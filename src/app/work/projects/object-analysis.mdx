## Overview

An AI-powered application for uploading an object image and receiving analysis of its identity, material or composition, condition, and historical or functional significance. The Express backend uses Google Generative AI for image analysis.

## Key Features

- **Image upload and analysis**: Accepts an object image (`POST /analyze`) and returns an AI analysis report.
- **PDF export**: `POST /download` generates an Object Analysis Report with the analysis date, AI result, and uploaded image when available.
- **Temporary uploads**: Uploaded images are processed for analysis rather than stored as a long-term gallery.

## Technologies Used

- Node.js and Express.js
- Google Generative AI
- JavaScript, EJS, Multer, and PDFKit

## Outcome

The project is a focused generative-AI workflow: file upload, image analysis, and PDF report generation.
