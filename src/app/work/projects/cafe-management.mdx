## Overview

A Smart Cafe Management System built with the MERN stack to support cafe operations: staff authentication, menu management, cart handling, order processing, billing, and administration.

## Key Features

- **Staff authentication**: Registration, login, password hashing, and JWT-protected API routes.
- **Menu management**: Search and filter menu items; administrators can add, update, and delete items.
- **Orders and billing**: Cart checkout, order status flow (Pending → Confirmed → Preparing → Ready → Completed), and billing management.
- **Admin dashboard**: Menu and order management for day-to-day cafe operations.
- **REST APIs and MongoDB**: Express APIs with Mongoose models for users, menu items, orders, categories, and payments.

## Technologies Used

- React and JavaScript
- Node.js and Express.js
- MongoDB and Mongoose
- JWT authentication

## Outcome

The project demonstrates full-stack development with authentication, REST APIs, and database-backed cafe workflows.
