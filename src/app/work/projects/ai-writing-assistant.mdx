## Overview

An AI-assisted writing tool that identifies spelling and grammar issues and suggests corrections. A React frontend calls Express routes for analysis, spelling, grammar, and authentication.

## Key Features

- **Text analysis**: `/api/analyze` endpoint for reviewing submitted writing.
- **Spelling and grammar**: Dedicated `/api/spell` and `/api/grammar` routes for issue detection and suggested rewrites.
- **Authentication**: Google OAuth and JWT-backed `/auth` routes.
- **Generative AI backend**: Google Generative AI used from the Express server so API credentials stay off the client.

## Technologies Used

- React and JavaScript
- Node.js and Express.js
- Google Generative AI
- Google OAuth and JWT

## Outcome

The project shows practical AI API integration, REST endpoints, and authentication in a focused writing-support product.
